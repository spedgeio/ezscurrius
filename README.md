# EzScurrius

<img src="icon.png" alt="EzScurrius icon" width="96">

A RuneLite plugin that makes Scurrius fights easier on the eyes and ears:

- Recolours the shadows of Scurrius' falling debris so they're easier to see
- Plays a sound when the food pile is ready to eat again

## Features

### Debris recolour

When Scurrius stomps, debris falls on the arena and a shadow shows where each piece will land. The plugin recolours the debris in a colour of your choice, magenta by default, so it stands out against the sewer floor. This helps if you're colourblind or find the shadows hard to see.

Only the colour changes. The debris lands in the same place at the same time as normal.

### Choese sound

You can eat from a food pile to heal to full once every ten minutes. When that cooldown runs out, the plugin plays the choese sound so you know the cheese is ready. If you don't like choese, turn it off or lower its volume in the settings.

To see the cooldown counting down, turn on **Scurrius food pile** in RuneLite's Timers & Buffs plugin.

## Settings

| Setting | Default | Description |
| --- | --- | --- |
| Recolour Debris | On | Recolour the falling debris so its shadow is easier to see |
| Debris Colour | Magenta | Colour of the falling debris |
| Only Original Colours | Blank | Recolour only faces with these original colours; leave blank to recolour every face |
| Choese Sound | On | Play a sound when the food pile is ready to eat again |
| Choese Volume | 50% | Volume of the choese sound |
| Debug Messages | Off | Describe new graphics and the debris model in chat while Scurrius is nearby |
